# SPEC-OFFLINE — Offline-First Asset Resolution

**Status:** Implemented · **Verified by:** `tests/offline.spec.mjs`, `tests/pwa.spec.mjs`, `npm run boot:check`
**Source of truth:** `tools/tnq-boot.js` (runtime) and `tools/apply-boot.mjs` (generator)

---

## 1. Deployment targets

| Target | How it is opened | Expected result |
|---|---|---|
| **Local / offline** | Double-click `index.html` (`file://`), no internet | Everything works from `./lib/`. Native fonts. Zero console errors. |
| **Zero-config hosting** | Any static host, e.g. GitHub Pages (`https://…`) | `./lib/` is served; Google Fonts load; the service worker caches everything. |
| **Installed app** | Home-screen icon after one online visit | Every page is served from the service-worker cache, including in airplane mode. |
| **Classroom LAN** | `npm run serve` → `http://<pc-ip>:8080` on the same Wi-Fi | Works while connected. A service worker needs https, so there is no offline install over plain http. |

## 2. Third-party library resolution protocol

Each module declares only the libraries it actually uses. The generator detects them:
Tailwind if the module already used it, Tone if it references `Tone.*`, confetti if it calls `confetti(`.
Modules that don't use Tailwind MUST NOT load it, because its Preflight reset would restyle them.

| Key | Global | Step 1: local | Step 2: CDN (exact pinned version) |
|---|---|---|---|
| `tailwind` | `tailwind` | `lib/tailwind.js` | `https://cdn.tailwindcss.com` |
| `tone` | `Tone` | `lib/Tone.js` | `https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js` |
| `confetti` | `confetti` | `lib/confetti.browser.min.js` | `https://cdn.jsdelivr.net/npm/canvas-confetti@1.6.0/dist/confetti.browser.min.js` |

### 2.1 Resolution steps (synchronous and order-preserving)

1. A parser-inserted `<script src="lib/X">` runs.
2. An inline probe follows it: `TNQB.n(key, global, cdn)`. If `window[global]` exists, the
   status is `local`. Otherwise it `document.write`s a `<script src="cdn">`, which executes before
   the next parser token, and the status becomes `cdn`.
3. The runtime block runs. For any key still missing its global, it installs an inert stub and
   sets the status to `stub`:
   - `tailwind` → `{config:{}}`, so `tailwind.config = …` doesn't throw.
   - `confetti` → a function returning a resolved Promise.
   - `Tone` → a recursive no-op Proxy. Construction, calls and property chains return the proxy;
     `then` resolves immediately; `state` returns `'suspended'`.

The resolved status is exposed as `window.TNQ.libs`, e.g. `{tone:'local'}`.

### 2.2 Why not `onerror="this.src='cdn'"`

That earlier pattern was **non-functional**. Per the HTML spec, a script element that has already
started is never re-fetched when its `src` changes, so the CDN copy was never loaded.
The registry test rejects it.

### 2.3 Known limitation

Chrome may block a `document.write`d cross-site script on 2G-class connections, and logs a warning
when it does. In that case step 3's stubs keep the module error-free.

## 3. Boot block format

`npm run boot` inserts this block immediately after `</title>` in every registered module.
It is idempotent, and `--check` exits non-zero when any file is stale.

```html
<!-- TNQ:BOOT:BEGIN generated by tools/apply-boot.mjs … -->
<script>window.TNQB={…}</script>                  <!-- probe helper (only if libs) -->
<script src="lib/Tone.js"></script>
<script>TNQB.n('tone','Tone','https://…/Tone.js')</script>
<script data-tnq-module="<basename>" data-tnq-fonts="<google fonts css2 url>">/* runtime */</script>
<!-- TNQ:BOOT:END -->
```

The runtime MUST NOT contain a closing script tag; the generator refuses to build if it does.
The runtime provides, in order: stubs (§2), web fonts (§4), the paint gate (SPEC-CORE §4.4), and the hub bridge (SPEC-CORE §3).

## 4. Font fallback matrix

Native stacks are the baseline. Web fonts are an enhancement. The Google Fonts stylesheet is
written only when `navigator.onLine !== false`, so an offline device makes no doomed request and
logs no console error. `TNQ.fonts` is `'web'` or `'native'`.

Every `font-family` declaration in a module `<style>` is normalised by the generator to:
the brand font(s), then the row below, then the generic family.

| Generic | Native fallbacks (in order) |
|---|---|
| `sans-serif` | `'Segoe UI'` (Windows), `'SF Pro Rounded'`, `'SF Pro Text'`, `-apple-system`, `BlinkMacSystemFont` (Apple), `system-ui`, `Roboto` (Android/ChromeOS), `'Helvetica Neue'`, `Arial` |
| `cursive` | `'Chalkboard SE'`, `Chalkboard` (Apple), `'Comic Sans MS'`, `'Segoe Print'` (Windows), `'Marker Felt'` |
| `monospace` | `'SF Mono'`, `'Cascadia Mono'`, `Consolas`, `Menlo`, `'Courier New'` |


## 5. Console-error budget

| Mode | Allowed console errors |
|---|---|
| `file://`, offline, `lib/` present | **None.** No network request is even attempted. |
| `lib/` missing, CDN reachable | Only `404` for the missing local files. |
| `lib/` missing, no network | Resource-load errors only. **No page errors (uncaught exceptions).** |

## 6. Test network modes (`tests/support/harness.mjs`)

| Mode | Simulation |
|---|---|
| `offline-file` | `file://` URLs plus `context.setOffline(true)`. |
| `cdn-only` | Local server returns 404 for `/lib/*`; CDN URLs are fulfilled from the local copies. |
| `nothing` | `/lib/*` 404 and every external request aborted. |
| `no-internet` | Local server reachable; everything external aborted (classroom LAN). |

## 7. Service worker (`sw.js`, generated)

- **Precache:** `./`, the hub, every registered module, `manifest.webmanifest`, `icons/*`, and every `lib/*` file used.
- **Cache name:** `tnq-<sha256 of all precached content, first 12 hex>`. Any edit produces a new
  cache, and old caches are deleted on activate (`skipWaiting` + `clients.claim`).
- **Pages (navigations, iframes, `*.html`):** network-first with a 3 s timeout, then the cache, then `index.html`.
- **Same-origin assets:** cache-first.
- **Google Fonts:** stale-while-revalidate in `tnq-runtime-v1`.
- **CDN URLs:** not intercepted.
